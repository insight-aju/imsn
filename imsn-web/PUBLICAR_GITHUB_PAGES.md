# Publicação no GitHub Pages

Suba os arquivos desta pasta no repositório do GitHub.

## Ativar GitHub Pages

1. Abra o repositório no GitHub.
2. Vá em **Settings**.
3. Entre em **Pages**.
4. Escolha:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: /root
5. Salve.

O link ficará parecido com:

```txt
https://insight-aju.github.io/imsn-web/
```

O PWA precisa ser aberto por HTTPS para instalação funcionar melhor. GitHub Pages já fornece HTTPS.
